# Task Management System - Frontend

This repository contains the **frontend** of the Task Management System project.

## Features

- User authentication and account management.
- Task management: create, update, delete, and track task status.
- Admin dashboard for managing users and tasks.
- Responsive UI built with **Bootstrap 5**.
- Separate pages for tasks, users, and settings.

## Technologies Used

- **HTML5 / CSS3 / JavaScript**
- **Bootstrap 5**
- Client-side form validation
- Modular folder structure for pages and scripts
